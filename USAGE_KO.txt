나이스 출결 자동 입력기 - 사용 방법
====================================

[처음 한 번]
1. 압축을 푼 폴더 전체를 원하는 곳에 둡니다. (exe만 따로 꺼내면 실행되지 않습니다)
2. NEIS_Attendance_RPA.exe 실행
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]

[매번 사용할 때]
1. [1. 브라우저 실행] → 열린 크롬/엣지 창에서 나이스 로그인
   → 학급담임 일일 출결 화면(번호/성명/마감 열이 보이는 화면)까지 이동
2. 엑셀 파일 선택 → [엑셀 검사]로 해석 결과 확인
3. 처음에는 '테스트 모드'를 켠 채로 [2. 자동 입력 시작]
4. 확인 후 테스트 모드를 끄고 실제 입력

[엑셀 양식] (1행 머리글, 한 행 = 한 교시)
  일자 | 학번 | 교시 | 출결구분 | 상태분류 | 시스템등록일시 | 사유
  - 교시: 조례, 1교시 ~ 7교시, 종례
  - 출결구분: 병/인정/미인정/기타 + 지각/조퇴/결(=결석)/결과
      예) 병지각, 인정조퇴, 인정결(결석), 미인정결과
  - 사유: 비워 두면 프로그램의 '기본 사유' 값을 사용
  - 엑셀을 수정했으면 반드시 저장(Ctrl+S) 후 사용

[처리 방법]
  - 지각: [마감] 입력 후 마지막 교시칸 클릭 (예: 조례,1교시 → 1교시)
  - 조퇴: [마감] 입력 후 첫 교시칸 클릭 (예: 3~6교시 → 3교시)
  - 결석: [마감]만 입력
  - 결과: 각 교시칸 팝업에 입력

[결과 확인]
  exe 옆 logs 폴더 → run.log(진행 기록), 처리결과.csv, 오류 화면 캡처
  ※ logs 폴더에는 학생 정보가 들어 있으니 다른 곳에 올리지 마세요.
